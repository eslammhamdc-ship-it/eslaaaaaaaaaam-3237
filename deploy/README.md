# عرض مجاني مؤقت للشركة

الإعداد الحالي لعرض ميدواي ببيانات تجريبية قبل شراء استضافة دائمة. `render.yaml` يستخدم خطة Free بدون قرص مدفوع. لم تُنشر الخدمة بعد. توفر المجاني وطلب التحقق يحددهما Render؛ لا نضمن النشر بدون بطاقة لكل حساب.

## حدود البيانات

قاعدة البيانات والمرفقات في `/tmp/midway-demo`. قد تبقى خلال فترة التشغيل نفسها، لكن لا تعتمد على بقائها بعد توقف الخدمة أو إعادة تشغيلها أو نشرها. الحسابات نفسها مؤقتة. قد تتوقف الخدمة المجانية عند عدم الاستخدام ويتأخر فتحها مجددًا. جهّز بيانات العرض قبيل الاجتماع، واستخدم بيانات تجريبية فقط.

إذا فقدت البيانات، أعد إنشاء المدير بنفس رمز الإعداد المحفوظ في إعدادات Render. الرمز لا يسترجع البيانات القديمة. التطبيق يعرض تنبيهًا لوضع العرض المؤقت. ترقية الخطة وحدها لا تنقل البيانات إلى قرص دائم.

## النشر اليدوي بدون Blueprint

1. في Render اختر **New + → Web Service**.
2. اربط GitHub واختر `eslammhamdc-ship-it/eslaaaaaaaaaam-3237` والفرع `codex/midway-branch-workspace`.
3. اترك Root Directory فارغًا واختر Runtime **Node**.
4. Build Command: `bash deploy/build.sh`.
5. Start Command: `bash deploy/start-demo.sh`.
6. اختر Instance Type **Free**. لا تضف Disk أو اشتراكًا مدفوعًا.
7. في Environment أضف `NODE_VERSION=24` ومتغيرًا سريًا باسم `MIDWAY_SETUP_TOKEN`. استخدم Generate إن ظهر، أو اختر رمزًا عشوائيًا طويلًا بنفسك (32 حرفًا أو أكثر). لا تشارك قيمته في المحادثة.
8. راجع أن السعر صفر والخطة Free قبل إنشاء الخدمة. إذا طلبت بطاقة رغم اختيار Free، توقف ولا تدخل بيانات دفع من أجل التجربة.
9. بعد نجاح النشر افتح رابط HTTPS، وأدخل رمز الإعداد في التطبيق وأنشئ مدير الفرع. أضف المديرين والموظفين ثم بيانات العرض.

احتفظ برمز الإعداد في إعدادات الخدمة المجانية لإعادة إنشاء الحسابات إن فُقدت البيانات. إنشاء أول مدير يُغلق تلقائيًا طالما يوجد حساب.

## النسخة الدائمة لاحقًا

راجع [PAID.md](PAID.md) و`deploy/render-paid.yaml`. يلزم نقل البيانات المطلوبة إلى قرص دائم واختبار النسخ الاحتياطية ومراجعة التكلفة. التطبيق يدعم فرعًا واحدًا؛ كل شركة مستقلة تحتاج خدمة وقاعدة بيانات منفصلتين.

## التحقق

`bash deploy/build.sh` ينفذ التثبيت والفحوص والاختبارات والبناء. `bash deploy/start-demo.sh` يشغّل العرض بقاعدة مؤقتة ويتطلب رمز إعداد. اختبارات المتصفح تستخدم قاعدة منفصلة. النجاح المحلي لا يثبت نجاح النشر أو توفر خطة مجانية لحسابك.
