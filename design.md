# Midway Flight Operations
Arabic-first RTL aviation command center. Web only; preserve template API and analytics.
Palette: #080f1c background, #0b1424 sidebar, #101c2e panels, #223047 borders, #eaf1fc text, #8d9db4 muted, #70baff blue, #ff974d orange, #4bd5ab success.
Typography: Cairo Arabic and Manrope Latin with system fallbacks. 24px gutters, restrained 12px panels, quiet shadows, no decorative imagery. Custom SVG charts and Lucide icons.
Right-hand sidebar, compact top bar, editorial title, unified date filters, responsive drawer and scrollable tables. RTL forms, LTR technical references.
Screens: dashboard, requests, clients, employees, reports. Request creation/edit, details with status history and attachment preview. Client create/edit. Shared request-based KPIs, currency-separated recorded financial totals, no rankings or arbitrary deltas.
Storage: five entities in browser IndexedDB; fictional seed data; private local Blob attachments, no public uploads. Explicit local-only/no-auth disclosures. Demo role controls not authorization. No integrations, paid services or new packages. Future authenticated backend and private storage.
Accessible validated forms, keyboard dialogs, loading/errors, empty states, transactional saves.
